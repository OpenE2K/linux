EMC2305 (I2C)

This device is a RPM-based PWM Fan Speed Controller for up to 5 fans.

Required properties:
- compatible: "smsc,emc2305"
- reg: I2C bus address of the device
- #pwm-cells: should be 2. See pwm.yaml in this directory for a description of
  the cells format.

Example:

i2c@0 {
	#address-cells = <1>;
	#size-cells = <0>;
	emc2305@2c {
		compatible = "smsc,emc2305";
		reg = <0x2c>;
	        #pwm-cells = <2>;
	};
};
